# 中国警察网公安英模二级英模模板验证记录

## 输入

- 入口链接: `https://gaym.cpd.com.cn/qggaxtejyxmf_25573/`
- 抓取范围: 中国警察网“全国公安系统二级英雄模范”栏目，模板覆盖 `index.html` 到 `index_9.html`；小样本配置先只跑 `index.html`。
- 目标字段: 姓名、详情链接、图片链接、栏目、列表摘要、正文、页面标题、meta 简介。
- 输出要求: 图片按人物姓名命名，记录保留；后续按性别分目录时不删除女性/未知。
- 验收口径: 小样本按第一页可见人物条目计数；全量按 10 个栏目页发现的详情链接计数。

## 勘察结论

- 栏目页为静态 HTML，第一页 `#nav04 .left ul a[href*='t_'][href$='.html']` 可命中 10 个详情链接。
- 分页由页面内 JavaScript `document.write` 拼出，模板不依赖分页选择器，改为显式列出 10 个 `start_urls`。
- 详情页为静态 HTML，标题在 `h1`，正文在 `.TRS_Editor`，正文图片为 `W020*.jpg`。
- 姓名从详情页标题冒号前截取，例如 `张凌峰：25载禁毒路...` -> `张凌峰`。
- 反爬风险: 低到中。栏目页和详情页请求模式可读，先推荐 `requests_jsl`；如果图片下载出现防盗链/非图片响应，再切浏览器模式。

## 推荐模式

- 推荐: `requests_jsl`
- 理由: 栏目页、详情页和图片 URL 均为静态资源，当前抽样请求返回 200。
- 备选: `browser`
- 切换条件: 图片失败率超过 10%、连续 403/429/521、或返回 HTML 挑战页。

## 频率

- 单并发。
- 页面/图片随机间隔: `5-8` 秒。
- 不和公安部同域任务并发；可与公安部任务作为不同域名并行。

- downloaded(sample): 待小样本运行后填写
- completed(sample): 待小样本运行后填写
